# CSF01 Capstone Brief

Cybersecurity Fundamentals capstone submission.

A security due-diligence review of ConnectSphere, a professional networking platform
preparing for an investor review. The memo prioritises the three most serious risks
(public unencrypted backups, an exposed admin dashboard with default credentials, and
stored XSS in forum posts), plus two systems-engineering recommendations.
